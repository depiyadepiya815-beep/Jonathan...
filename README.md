# JONATHAN-MD
Starter WhatsApp bot using the official WhatsApp Cloud API. Supports Sinhala default replies, `!help`, and `!about`.

This is source code only; it is not online yet. It requires a Meta developer app, WhatsApp Cloud API credentials, and a public HTTPS webhook.

## Run
1. Install Node.js.
2. Run `npm install`.
3. Copy `.env.example` to `.env` and enter your Meta credentials.
4. Run `npm start`.

Never upload `.env` or share access tokens, OTPs, or WhatsApp pairing codes. Upload the other files to GitHub. See https://developers.facebook.com/docs/whatsapp/cloud-api/ for official setup.
